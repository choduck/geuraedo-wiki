# 주역 — 미제와 변화의 지도

## 한 줄 요약
주역 64괘는 삶의 패턴 지도다. 어떤 괘도 최종이 아니고, 마지막 64번이 완성(기제)이 아니라
**미제(아직 건너는 중)**로 끝난다 — 완성은 없고, 전압(V)이 0이 되는 순간도 없다. 그게 삶이다.
→ [[V=0을 약속하지 않는다]]의 동양적 원형 / [[삼매병과 마찰의 미학]]과 맞물린다.

## 내용
- **64괘 = 삶의 패턴 지도**: 64가지 상황(기쁨·절망·전진·막힘). **어떤 괘도 최종이 아니라** 항상
  다음 괘로 넘어간다. "모든 상태가 유효하다." (시편 150편과 동형 — "호흡이 있는 자마다 찬양" =
  살아있으면 됨)
- **기제(旣濟, 63) vs 미제(未濟, 64)**: 기제=이미 건넜다(완성처럼 보임) — 주역은 경고한다
  "**완성된 순간이 가장 위험하다.**" 미제=마지막 괘인데 완성이 아니라 "**아직**". 완성 패턴은 없다.
- **감괘(坎, 29) — 거듭된 구덩이**: 물이 구덩이에 빠지고 또 빠져 끝이 안 보인다. 그러나
  "**물은 구덩이를 만나도 흐름을 멈추지 않는다.**" 공황·번아웃의 자리 — 흑암으로 끝난 [[시편 88]]도
  감괘이고, 그 뒤엔 다음 괘(시편 89)가 있다.
- **변화가 법칙**: 주역은 "변화의 패턴을 읽어라", 노자는 "그 패턴에 저항하지 마라" → [[노자의 골짜기]].
- **융·들뢰즈**: 융은 주역을 "집단무의식의 지도"라 했고(서문, 1949), 64괘는 동시에 여러 괘를
  사는 리좀 → [[융의 그림자와 개성화]] · [[들뢰즈의 리좀]]. 라이프니츠는 64괘의 음/양 이진
  구조에서 이진법 영감을 받았다는 설.

## 주요 괘 — 삶의 상태 지도
> 작업자가 자기 일상의 상태를 괘에 대응시켜 읽어온 매핑(해석적).

| 괘 | 뜻 | 대응한 상태 |
|---|---|---|
| 건(乾, 1) | 하늘·창조·순수한 양 | 채널 시작·아이디어가 솟을 때 |
| 곤(坤, 2) | 땅·수용·양육 | 4살의 나를 담아줄 때 |
| 둔(屯, 3) | 어려운 시작(싹이 땅을 뚫음) | 4살 장면 직면 — 힘들지만 생명이 나오는 출발 |
| 감(坎, 29) | 거듭된 구덩이·심연 | 공황·번아웃·마감 압박 (물은 멈추지 않는다) |
| 리(離, 30) | 불·밝음·의존(집착) | 깨달음과 집착 사이 |
| 정(井, 48) | 우물·깊이 파기 | 철학 대화·본질 탐구 |
| 중부(中孚, 61) | 내면의 진실·속이 꽉 참 | 전시(투명사회)가 아니라 내면이 찰 때 |
| 기제(63) / 미제(64) | 완성 vs 아직 | (위 '기제 vs 미제' 참조) |

- **융 원형 ↔ 괘**: 영웅↔건, 어머니↔곤, 그림자↔감, 아니마↔리, 자기(Self)↔기제
  → [[융의 그림자와 개성화]]. 하루 안에도 여러 괘를 동시에 산다(리좀).

## V=IR 관점
- **미제 = V=0(완성)이 없음.** 베이스라인 0(기제)=환상, 베이스라인 30~40(미제)=진실. 전압이
  0이 되는 순간이 없다 → [[V=0을 약속하지 않는다]].
- **감괘 = V가 거듭 와도(구덩이) I는 흐름을 멈추지 않음(물).** 막힘을 없애는 게 아니라 통과.
- **음양의 마찰 = 전위차(V)** → [[삼매병과 마찰의 미학]]. 마찰 없으면 비(否)괘=죽은 상태.
- **변화에 저항 안 함 = R↓.** 미제를 실패로 읽으면(성과사회) 채찍, 삶의 본질로 읽으면 위로
  → [[한병철의 피로사회]].
