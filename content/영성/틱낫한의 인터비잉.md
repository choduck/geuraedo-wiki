# 틱낫한 — 인터비잉과 마음챙김

## 한 줄 요약
틱낫한은 마음챙김을 일상의 실천으로 대중화했고, **인터비잉(Interbeing, 상호존재)** — 모든 것은
서로 안에 있고 연결돼 있다 — 을 말했다. 불교이면서 심리학이고, 영성이면서 실천. 고립된 V가
연결 속에서 흐른다. → [[마음챙김]] / [[불교 무상과 무아]]와 맞물린다.

## 내용
- **인터비잉(상호존재)**: 모든 것은 홀로 존재하지 않고 서로 안에 있다(연기법의 현대적 표현).
  종이 한 장 안에 구름·비·나무·햇빛이 다 들어 있다.
- **마음챙김의 실천**: 거창한 수행이 아니라 걷기·설거지·호흡 같은 일상에서 지금에 깨어 있는 것 —
  불교이자 심리학이자 실천 → [[마음챙김]] · [[하루키의 우물과 루틴]].
- **고통의 자리**: 고통을 밀어내지 않고 아기처럼 품어 알아차리면 변형된다(억압도 폭발도 아닌 돌봄).

## V=IR 관점
- **인터비잉 = 고립된 V가 연결 속에서 풀림.** "나만 그런 게 아니다" — 고통이 관계망 속에 있을 때
  R(고립)이 낮아진다 → [[하버마스와 호네트]](인정) · [[네프의 자기연민]](보편적 인간성).
- **마음챙김 실천 = 현재로 R↓** → [[마음챙김]] · [[디폴트 모드 네트워크]].
- 고통을 없애는 게 아니라 품어 알아차림(V=0 아님).
