# 프랑스혁명과 5.18 — V가 새 R이 되는 자리

## 한 줄 요약
두 역사적 순간을 V=IR로 겹쳐 읽는다. 둘 다 외부 억압이 아니라 **임계점을 넘은 V(분노·생명력)의 폭발**이었고, 초기 혼란 속에서 자발적 질서(파리코뮌·광주 시민공동체)가 피어났다가 결국 배신·진압당했다. 핵심 통찰: **승리한 V가 새 R이 된다** — 짓밟힘의 자리는 비지 않고 주인만 바뀐다. → [[레닌의 비극]]과 같은 구조.

## 내용
- **프랑스혁명(1789~1799)**: 바스티유 습격 → 루이 16세 처형 → 공포정치(로베스피에르·단두대) → 나폴레옹으로 귀결. → [[나폴레옹]]
- **5.18(1980)**: 계엄군의 폭력 → 시민 봉기 → 고립된 열흘의 시민공동체 → 진압 → (장기적으로) 87년 6월 항쟁으로 이월.

| | 프랑스혁명 | 5.18 |
|---|---|---|
| 폭발한 것 | 민중의 분노(V) | 시민의 분노(V) |
| 자발적 질서 | 파리코뮌 72일 | 광주 시민공동체 열흘(음식 나눔·헌혈·자치) |
| 단기 결말 | 승리(혁명) | 진압 |
| 배신/귀결 | 공포정치·나폴레옹 | 전두환 집권 |
| 죽은 자 | 왕을 죽임 | 시민이 죽음 |
| 장기 궤적 | 근대 민주주의의 토대 | 폭도 낙인 → 뒤늦은 복권, 87항쟁의 씨앗 |

- **결정적 차이**: 프랑스혁명은 왕을 죽였고 5.18은 시민이 죽었다. 프랑스혁명은 나폴레옹으로, 5.18은 87년 항쟁으로 이어졌다. 단기로는 프랑스가 승리·5.18이 진압이지만, **장기 궤적은 정반대로 갈린다.**
- **혁명이 스스로 공포정치가 됨**: 프랑스혁명의 배신이 더 비극적이다. V가 R(절대왕정)을 무너뜨렸는데, **승리한 V가 새 R(공포정치)이 됐다.** 혁명 참가자들이 그 공포정치에서 처형당했다(타루 아버지가 사형 집행인이 되는 구조 — 혁명이 자기 아들을 적으로 만든다). → [[레닌의 비극]]

## 곁가지: 1830년 7월혁명 — 같은 구조의 축소판
- **팩트**: 나폴레옹 몰락(1815) 후 부르봉 왕정 복귀. 샤를 10세가 언론 자유 폐지·의회 해산·선거권 축소 칙령을 내리자 1830년 7월 27~29일 '영광의 사흘(Trois Glorieuses)' 시가전 → 샤를 10세 망명. 들라크루아 「민중을 이끄는 자유의 여신」이 이 혁명을 그린 것.
- **그런데 공화국이 아니라 또 다른 왕(루이 필리프, '시민왕')이 들어섰다.** 피는 민중이 흘리고 열매는 부르주아가 챙김 → 18년 뒤 1848년 2월 혁명. **V가 샤를 10세(R)를 무너뜨렸지만 승리 쪽이 새 R이 됨** — 프랑스혁명·5.18과 동형.
- 벤야민은 7월혁명 첫날 저녁 파리 곳곳에서 사람들이 **약속도 없이 동시에 시계탑에 총을 쏜** 사건을 인용한다(테제 15) — 균질한 시간 자체를 멈추려는 무의식적 몸짓. → [[벤야민의 역사의 천사]]

## V=IR 관점
- **혁명의 일반 공식**: 절대왕정(R) → 혁명(V 터짐) → 공화국(새 R) → 다시 쌓임 → 나폴레옹. 전위차는 결코 0이 되지 않는다 → [[V=0을 약속하지 않는다]].
- **"그래도 괜찮아"의 자리**: 5.18은 진압당했지만 그게 씨앗이 되어 역사를 바꿨다. **"진압당했어도 그래도 괜찮아, 씨앗이 되었다"** — 채널 이름 '그래도 괜찮아'의 정신과 5.18이 정확히 겹친다. 이김/짐의 단기 결과가 아니라, 짓밟힌 자리에서 무엇이 이월되는가(벤야민의 '약한 메시아적 힘'). → [[벤야민의 역사의 천사]]
- **집단 편도체**: 양쪽 모두 시민의 분노(V)와 권력의 공포(R)가 충돌. 공포정치는 혁명 후 R을 극한으로 높여 V를 통제하려던 시도였다. → [[권력과 편도체]]
