# 배낭과 배낭

## 한 줄 요약
**배낭** = 각자 등에 진, 남에게는 안 보이는 짐(트라우마·불안·계산서·안 풀린 것).
관계는 「배낭 없는 깨끗한 두 사람」이 아니라 **배낭과 배낭이 만나는 것** —
대신 지어주거나 내려놓게 하는 게 아니라, **서로 배낭이 있음을 알아보는 것**.
못 벗는다. 바뀌는 건 지는 법. → [[들고 걷기]] · [[V=0을 약속하지 않는다]]

## 내용

### 정의 — 카드 14의 원어
교보문고에서 나온 운영자 이미지(카드 14). 철학 차용이 아니라 **몸에서 뽑은 원어**.
카바레로의 「기울어짐」, 슬로터다이크의 「거품·공동면역」, 아렌트의 「복수성」이
같은 산의 다른 번역판으로 붙는다.
→ [[카바레로의 기울어짐]] · [[슬로터다이크의 수행하는 삶]] · [[아렌트의 사유와 고독]] · [[로제타석 — 목소리 능선]]

### 두 단계 (시야)
1. **내 배낭이 너무 무거우면 남 배낭이 안 보인다.**  
   노이즈가 CPU 100% → 세상에 힘든 사람은 나뿐인 것 같다.
2. **노이즈가 줄면 남도 배낭을 멘 것이 보인다.**  
   「남이 보이고, 길의 꽃도 보이고, 와이프도 보이고」—  
   타인의 배낭이 보이기 시작함 자체가 **치유의 신호**(내 짐이 조금 가벼워진 증거).

### 여섯 갈래
1. **못 벗는다 — 지는 법만 바뀐다**  
   「언젠가 배낭 딱 벗고 홀가분」= V=0 환상. 베이스라인 30~40.  
   치유 = 제거가 아니라 **carrying**. 배낭 멘 자세는 원래 살짝 기운다(카바레로) — 꼿꼿이 서려 해서 등이 더 아팠다.

2. **제일 무거운 짐은 이름표 없는 짐**  
   언어화되지 않은 V가 제일 무겁다. 소설·대화·카드 = 짐에 이름표 붙이기.  
   무게가 확 준다기보다, 자세를 고칠 수 있게 된다.

3. **내가 다 안 쌌다**  
   구조·대타자가 넣은 짐. **내 탓 아님(구조가 쌌다) + 내 것 됨(내가 진다)** — 자책도 남탓도 아닌 사이.

4. **관계 = 만나고, 가끔 부딪힌다**  
   갈등 = 사람 대 사람이 아니라 **배낭 대 배낭 충돌**.  
   남 배낭 속은 다 못 봄(케노마). 할 수 있는 건 대신 지기(불가능)가 아니라 **나란히 걷기(현존)**.

5. **짐만이 아니라 장비도 있다**  
   나비포옹·어깨 감각·카드·통찰 = 생존 키트.  
   수행(Übung) = 배낭 *비우기*가 아니라 **배낭 정리**(죽은 짐 vs 장비). 매일 다시 싼다(미제).  
   → [[슬로터다이크의 수행하는 삶]]

6. **채널 = 광장에서 배낭을 연다**  
   내 짐을 보여 주면 남이 자기 등을 돌아본다.  
   상처 입은 치유자·견유(디오게네스) — 광장에서 배낭을 열어젖히는 사람.  
   → [[데리다의 파르마콘]](파르마코스)

### 봉합 금지
「그 무게가 널 강하게 만들었어」로 미끄러지지 않는다.  
배낭은 진짜 무겁고 등을 아프게 한다. 독은 독.  
은혜는 무게가 *선물이라서*가 아니라 — 못 내려놓고 오래 걸어서 **이 산의 지도를 읽게 됐다**는 데 있다.  
무게를 미화하는 순간 4살이 지워진다(아도르노). → [[화해하지 않는 문학]]

### 채널 무기
라캉·데리다보다 진입장벽이 낮다. 「배낭」을 듣는 순간 자기 등을 만진다.  
영상 시리즈 뼈대 후보: 위 여섯 갈래 = 6부작.

### 「들고 걷기」와의 관계
| | [[들고 걷기]] | 이 페이지 |
|---|---|---|
| 층 | 윤리·전통 질문 | 일상 이미지·관계 문법 |
| 동사 | 들고 / 걷기 | 메고 / 알아보기 / 열기 |
| 관계 | 전통이 동행하는 법 | 배낭끼리의 만남·충돌·현존 |

같은 carrying. 다른 해상도.

## V=IR 관점
- **V** = 배낭의 무게(긴장·상처·계산서). 벗을 수 없음 = V≠0.
- **I** = 지는 법·메는 자세·광장에서 열어 흐르게 하기·나란히 걷기.
- **R** = 「배낭 없이 만나라」는 환상 · 대신 지거나 내려놓게 강요 · 무게 미화(거짓 화해) · 자기 배낭만 기소하는 눈.
- 목표: 빈 배낭이 아니라, **남 배낭이 보이는 시야**와 **장비로 정리된 carrying**.
