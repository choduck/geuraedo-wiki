# 리처드 세넷의 장인정신

## 한 줄 요약
리처드 세넷(Richard Sennett, 1943~)은 미국 출신 **사회학자·도시학자**다.
『The Craftsman』(2008)의 핵심: **장인정신(craftsmanship) = 일 자체를 위해 일을 잘하려는
기본 충동.** 손과 머리가 분리되지 않은 채, 재료의 **저항**·**애매함**과 대화하며 숙련이 자란다.
채널 문장: **장인은 고통을 없애려는 사람이 아니라, 저항을 적으로 두지 않는 사람** —
「안 됨」을 적군이 아니라 **재료·현실의 회신**으로 듣는다.
→ [[들고 걷기]] · [[삼매병과 마찰의 미학]] · [[아렌트의 사유와 고독]]

## 내용

### 누구인가
- 사회학·도시·노동·손기술을 연구. 대중 스타라기보다 노동·디자인·조직론에서 자주 인용되는 학자.
- 한나 아렌트의 영향권. 『장인』은 스승의 animal laborans / homo faber 구분을 **다시 읽으며**
  손일 안의 사유를 구출하려 한다. → [[아렌트의 사유와 고독]]
- 인접 저작: 『The Corrosion of Character』(신자유주의와 성격의 부식), 『Together』(협력).

### 장인정신의 정의
- 「일을 잘함」의 초점은 **자기 과시가 아니라 일·품질**.
- 목수만이 아니다 — 프로그래머·의사·연주자·부모·시민의 **숙련된 실천**까지 확장.
- 대략 오랜 반복 실천(흔히 말하는 1만 시간 운)으로 손–머리 리듬이 붙음. 측정이 아니라 **무게**.

### 아렌트와의 긴장
| | 아렌트(세넷이 읽는 도식) | 세넷 |
|---|---|---|
| animal laborans | How?에 매몰, 손일을 아래로 | 만드는 과정 안에 이미 생각·느낌이 있다 |
| homo faber | Why? — 멈추고 판단 | 손일이 판단의 안내자가 될 수 있다 |

손–머리가 분리되면 **머리가 먼저 병든다.** 사유는 일이 끝난 뒤에만 오지 않는다.

### 저항(resistance) — 재료가 하는 「말」
신비한 속삭임이 아니라 **작업 피드백**: 재료·도구·현실이 뜻대로 안 되는 방식으로 정보를 준다.

1. **발견한 저항(found)** — 옹이, 진흙, NPE, 레거시 제약. 세계가 먼저 건넨 것.
2. **만든 저항(made)** — 초안을 지우고 다시 그림, 일부러 어려운 연습. 학습 장치.

장인의 기술(요지):
- 문제를 **다시 쓰기**
- 오래 걸리면 **템포·각도 조정**
- **가장 용서하는(들어가기 쉬운) 요소**부터 동일시해 들어가기 — 큰 적부터 전쟁하지 않음.

★ 저항 ≠ 고통. 저항은 「안 됨」의 사실이고, 고통·공황은 그에 **붙을 수 있는** 몸·의미 층.
세넷 본령은 전자. 후자로의 확장은 채널 합성(아래).

★ 모든 장애가 스승은 아님. 착취적 일정·잘못된 도구는 「재료의 지혜」가 아니라 **바꿀 조건**.

### 애매함(ambiguity)
저항 = 신호가 셈(에러·막힘).  
애매함 = 신호는 있는데 **해석이 둘 이상** / 이해가 안 닫힘.

코딩 예:
- 버그인가 스펙인가 (그리드 소트)
- null = 없음 / 미배정 / 아직 로딩 전
- 돌아가는 레거시 — 왜 도는지 모름 (성공이 이해를 가림)
- 「사용자 친화적으로 빠르게」— 측정 불가능한 요구
- AI 패치가 초록불 — 저항 없음 ≠ 애매함 없음

장인 손: 빨리 하나로 못 박지 않고 **판결 유예 + 탐침**.  
성공 기준 = 확신이 아니라 **다음 실험이 정해짐**.  
problem-solving과 problem-finding이 한 리듬.

### 채널·코딩 적용 (해석)
> 장인은 고통을 없애려는 사람이 아니라, 저항과 대화할 줄 아는 사람이다.  
> → **저항을 적으로 두지 않는 사람.**

| | 적으로 둘 때 | 대화로 둘 때 |
|---|---|---|
| 코딩 | 에러 = 수치·기소 | 에러 = 회신. 「뭐라고 하나?」 |
| 말하기 | 더듬 = 없앨 결함 | 막힘 = 호흡·속도 정보 |
| 부동산·일확천금 OS | 마찰 0 = 성공 | 마찰 = 루저 표식 (세넷의 반대 꿈) |

책상 문장: 「적으로 두지 말자. 뭐라고 하나?」  
대화의 성공 ≠ 에러 0 / 고통 0. **다음으로 만질 곳이 정해짐.**

공황·AI 생계 불안은 세넷의 「재료 저항」과 **동일하지 않다.**  
기술·도구의 결이 바뀌는 부분은 세넷으로 대화 가능.  
생계·자존의 흔들림은 [[들고 걷기]]·[[불안의 세 층위]] 자리. 뭉개지 말 것.

## V=IR 관점
- **저항(재료의 안 됨)** ≈ 행함에 붙는 마찰 — [[삼매병과 마찰의 미학]]의 전위차와 공명. 다만 세넷 용어 ≠ V 전체.
- **대화·다음 손** = I — 없애기 전쟁이 아니라 흐름.
- **저항=실패·루저로 읽는 OS / 한 방 도약** = R — 일확천금·V=0 판매.
- 장인정신 ≠ 아무 고생의 성화. 「일과의 대화가 되는 반발」과 「바꿔야 할 억압」을 가림.
- → [[V=0을 약속하지 않는다]] · [[들고 걷기]]
