# 슬로터다이크의 수행하는 삶

## 한 줄 요약
페터 슬로터다이크(Peter Sloterdijk): **인간은 믿는 존재가 아니라 반복하는 존재(homo repetitivus)**다.
치유·삶은 「한 방 깨달음」이 아니라 **매일의 수행(Übung)**. 독일어 **Spannung(긴장)**은 물리학에서 **전압(voltage)** —그가 말한 **수직 긴장(vertikale Spannung)**과 채널의 **V**는 같은 단어다. 없앨 수 없다(V≠0).
단, 「더 높이」가 검사에게 납치되면 V=0 환상의 고급판이 된다. 해독제: [[주역|미제]] + I>0.
→ [[V=0을 약속하지 않는다]] · [[들고 걷기]] · [[카바레로의 목소리]]

## 내용

### 1. 수행하는 삶 — 매일 재컴파일
대표작 『너는 너의 삶을 바꿔야 한다』. 자기계발서가 아니라 반대 지점.
- 너를 만드는 건 신념이 아니라 **매일 반복하는 훈련**.
- 인간은 한 번 build해 끝나는 바이너리가 아니라, 죽을 때까지 도는 **런타임**.
- 종교를 「믿음 체계」가 아니라 **수행 체계(spiritual regimes)**로 다시 읽음.

채널 번역: 카드·나비포옹·어깨 감각·관(시스템3) = askesis(수련) 프로토콜.
「막힌 날 한 장」이 수행이다. → [[시스템 1·2·3 프레임워크]]

### 2. 수직 긴장 = 수직 전압 (Spannung)
인간은 **위에서 끌어당기는 것들**(성인·현자·곡예사·이상)의 장 안에서 산다.
그 당김이 없으면 수행 자체가 불가능하다. 신이 죽은 뒤에도 전압은 남고, 흐르는 방향만 바뀐다(세속화된 초월).

**V=IR과 글자 그대로 포개짐:**
> 수직 긴장(Spannung)을 0으로 만들려는 것 = V=0 환상.

진짜 문제는 전압의 크기가 아니라 **방향(I)**:
| 회로 | 결과 |
|---|---|
| V가 대타자의 가짜 정상(「유창해져라」)으로 흐름 | 감전·독 |
| V가 정상 없는 수행(미제)으로 흐름 | 약 |

같은 전압, 다른 배선. → [[라캉의 대타자]] · [[데리다의 파르마콘]](용량이 독을 만든다)

**밧줄 구분:** 카드 33 「밧줄 놓기」= 시스템1 vs 대타자의 *수평* 줄다리기.
그걸 놓아야 낭비전압이 *수직* 수행으로 재배선된다. 다른 밧줄이다.

### 3. 취약한 인간(homo immunologicus)
인간은 본능 방화벽 없이 태어난 **존재론적으로 노출된** 동물(결핍 존재).
살기 위해 면역을 스스로 짓는다 — 생물학적 / 사회적 / **상징적**(종교·의미·의례·예술).

채널 적용:
- **V=IR·카드·채널** = 상징적 면역 아키텍처
- **불안** = 면역이 켜져 있다는 신호(idle CPU). 끄면 죽음 → V≠0
- **검사(「유창해야」)** = 자가면역 — 지키려던 몸을 공격. 끄지 말고 **재조정**
- **나비포옹** = 면역 훈련(catch 블록). 병원체 0이 아니라 처리 능력
- **거품(spheres)·공동면역** = 관계는 혼자 짓는 요새가 아님 → [[배낭과 배낭]]

취약함은 결함이 아니라 **창조의 엔진** — 단, 구멍을 미화하지 않는다. 안 닫히니까 평생 짓는다(미제).

### 4. 냉소 vs 견유 — 채널의 정체
| | 냉소(Zynismus) | 견유(Kynismus) |
|---|---|---|
| 태도 | 「다 알지만 어차피…」계몽된 체념 | 디오게네스 — 몸으로, 아래에서, 광장에서 |
| 위험 | 58년 고통 뒤 제일 쉬운 함정 | — |
| 채널 | — | 더듬는 목소리로 유튜브에 나가 말하기 |

추방된 자(파르마코스)가 광장으로 돌아와 진실을 말하는 것. → [[데리다의 파르마콘]] · [[배낭과 배낭]](광장에서 배낭을 연다)

### 5. 함정 — 검사가 「더 높이」를 훔친다
「너는 너의 삶을 바꿔야 한다 / 수직 긴장 / 더 높이」는 대타자가 좋아하는 문장이다.
잘못 들으면 「수련이 부족해서 아직 더듬는다」= V=0 환상의 고급판.
자기최적화 비판·「인간 농장」논쟁도 있는 논쟁적 인물 — 정직하게 열어 둔다.

**안전핀 (이미 가진 것):**
1. **미제** — 깃발 꽂을 정상 없음. 능선을 걷는 것 자체가 목적. → [[주역]]
2. **I>0** — 목표가 감전 제거(V=0)가 아니라 **감전 내성**. → [[들고 걷기]]

### 6. 십자 좌표 — 수직 × 수평
| 축 | 누가 | 내용 |
|---|---|---|
| **수직** | 슬로터다이크 | 매일의 수행 · 자기 초월(단, 미제·I>0) |
| **수평** | [[카바레로의 목소리]] | 듣는 귀를 향해 기울기 · 관계 · 배낭 |

수직만 → 자기최적화 러닝머신(검사가 좋아함).  
수평만 → 성장·수행이 빠짐.  
채널은 교차점에 선다.

### 세넷과의 구분
[[리처드 세넷의 장인정신]] = 일·재료와의 *대화*(손의 피드백).  
슬로터다이크 = 자기 훈련·수직 당김(*anthropotechnics* 층).  
포개지되 같은 개념 아님. 저항을 적으로 두지 않기(세넷) + 매일 반복(슬로터) = 다른 능선.

## V=IR 관점
- **V** = Spannung — 없앨 수 없는 수직 긴장·면역 idle. 「0으로」가 오진.
- **I** = 배선 방향 — 가짜 정상으로 흐르면 감전, 미제 수행·채널로 흐르면 약. 견유=몸으로 흐르는 I.
- **R** = 검사가 훔친 「더 높이」·냉소·요새-면역(배제만 하는 벽)·자가면역으로서의 검사.
- 목표: V=0이 아니라 **잘 훈련된 catch 블록**(감전돼도 괜찮아지는 것).
