# 프롬 — 자유로부터의 도피, 존재냐 소유냐

## 한 줄 요약
에리히 프롬은 "자유가 주어지면 인간은 오히려 권위에 복종하려 한다"고 했다(자유로부터의 도피).
자유는 고독·불안하니까. **더듬는 채로 말하는 자유**가 무서워 유창한 척·침묵·회피로 도망친다.
또 '소유냐 존재냐' — 유창함을 소유해야 완전하다(V=0)가 아니라, 더듬는 채로 존재함이 이미 완전하다.
→ [[V=0을 약속하지 않는다]] / [[라캉의 대타자]]와 맞물린다.

## 내용
- **자유로부터의 도피(Escape from Freedom)**: "자유가 주어졌을 때 인간은 오히려 권위에 복종하려
  한다." 자유는 고독하고 불안하기 때문. 강한 지도자를 향한 욕망도 "내 불안을 대신 책임져줄
  아버지"를 원하는 것 → [[라캉의 대타자]].
- **말더듬 회피 = 자유로부터의 도피**: 진짜 자유는 "더듬는 채로 말해도 된다"는 것. 그런데
  유창한 척·침묵·회피로 대타자("유창해야 해")에 복종한다. **더듬는 채로 말하는 자유가 더 무서웠던 것.**
- **존재냐 소유냐(To Have or To Be)**: 소유 모드 = "유창함을 소유해야 완전한 인간"(= V=0 환상의
  극단). 존재 모드 = "더듬는 채로 존재하는 것이 이미 완전하다." 채널이 하는 일 = **소유 모드 → 존재 모드 전환**.

## V=IR 관점
- **회피·복종 = R을 남에게 넘김.** 자유는 R(책임·불안)을 내가 떠안는 것이고, 복종은 그 R을
  권위에 넘기는 것 — 후자가 편해서 도망간다. 회피가 곧 자유의 포기.
- **소유 모드 = V=0 환상.** 유창함을 '소유'해 완전해지려는 시도 → [[V=0을 약속하지 않는다]].
- **존재 모드 = V를 안은 채 존재(R↓).** 더듬는 채로 말하는 것 = 자유를 떠안는 것 → [[키르케고르의 불안과 도약]].
